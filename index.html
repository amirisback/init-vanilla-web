Key Advantages

Why choose this vanilla setup over heavy client frameworks for landing pages and high-performance microsites?

Zero Bloatware

No virtual DOM overhead, no hydration delays, and no mega-sized JavaScript vendor bundles. Fast and light.

Tailwind CSS v4

Next-generation CSS-first styling via @tailwindcss/cli. Instant builds without legacy config files.

Strict TypeScript

Enforce strict compiler rules with zero-suppression policy. Catch errors early with complete IDE auto-completion.

Instant Setup

Run npm run build and npm run serve to develop locally with pure native scripts.

Quickstart Commands

Clone, install, compile, and run your vanilla web application in seconds.

bash • npm scripts 
# 1. Install dependencies
npm install

# 2. Build CSS (Tailwind v4 CLI) and TypeScript (tsc)
npm run build

# 3. Start local static preview server (http://localhost:3000)
npm run serve

# 4. Watch mode during development
npm run watch:css
npm run watch:ts
